Do not publish confidential internal approval materials in this record.

The mapping in `apps/web/src/service-icons.ts` and separate image component permit switching to neutral text badges without rebuilding game structures. This technical replaceability does not itself settle usage rights.

## Stack & Survive artwork

Current board geometry, resource shapes, traffic markers and status effects are generated by project code. No third-party game-art packs are included by this change. Later imported assets need their own source and license entries; do not assume a whole hosting site is CC0.

`apps/web/src/building-art.ts` creates original project geometry for the cloud uplink, modular processing hub, layered SQL vault, memory accelerator and security gateway. `apps/web/src/environment-art.ts` creates the indoor floor tiles, rack rows, cooling/utility equipment, conduit, lighting and safety markings (original project code, introduced in #81; no third-party files imported). Environment is decorative and cached independently from buildings. These modules contain no copied third-party artwork or Azure SVG path data. Official badges are separate DOM images, not baked into these shapes. Actual game-art PNG/WebP production remains subject to the post-environment #91 quality review; procedural geometry is not described as a delivered sprite set.
