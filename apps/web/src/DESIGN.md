# First-run clarity presentation contract

## Scope and audience
Computer B owns title, briefing, opening, WorldGuide copy, phase arrival and local action explanations. First-time judges must see Black Friday, duration, rising demand/bots and App/Cache/Edge choices before Learn. Preserve existing components; no GameResult, backend, simulation, economy, art or submission changes.

## Existing visual language
Keep the authored title data-center backdrop and cyan Start Game as the dominant action. Navy surfaces (#071e31/#0b2235), pale text (#ecf7fc/#cce5ef), cyan emphasis (#72dce9), amber threats (#ffbc7a), mint recovery (#92e6b9). System body type; existing Impact wordmark. No new assets/fonts/dependencies or instrumentation packages in this presentation-only change.

## Typography and spacing
Brief label14px uppercase, statement18px, details14px; compact landscape12–14px. Existing4px spacing grid,8/12/16px gaps and16px surface padding. Start remains44px minimum hit area, existing larger desktop treatment retained.

## Layout and content
One compact mission strip between logo and challenge/start controls. Two lines of scenario/forecast and one line of tools. Short landscape uses compact title typography, brief summary, bounded controls; essential Start and mission stay in initial viewport. Details may scroll on smaller unsupported heights; portrait gate unchanged.

## Primitives and states
MissionBrief derives duration/first/final rates and bot ratio from selected workload. Countdown reuses its summary, never owns time. Existing HUD phase-detail is reused after integrating parallel work from main; arrival derives from observed snapshot, visible for first2 processed ticks, pointer-events:none, no interactive focus or simulation calls. No second banner/live region. Existing WorldGuide remains the only tutorial and its persistence key/stages unchanged. Accessible action labels stay stable; visible descriptions and tooltips explain effects and real provisioning delays.

## Motion and accessibility
Arrival fade/translate180ms only, no screen recolor. Reduced motion removes animation but retains text for the same observed phase window. Phase announcement is one polite status per phase, not per-second live readouts. Pause/error/result hides transient arrival. Color always paired with bot text. No modal or paused-time addition. Existing keyboard/portrait/focus controls preserved.

## Validation
Existing title/world primitives are the reference, not a new marketing style. Test1440x900,1920x1080,1366x768,844x390 title/countdown/normal/spike/recovery/bot. Unit alternate workload proves no duplicated scenario values. Existing simulation suite preserves scoring. Actual stranger comprehension and human2-second scan cannot be claimed from AI review.

## Accepted limits
No generic tooling or framework migration; existing project build/test tooling used. Headless screenshots establish layout, not physical device/human acceptance. Performance claims require measurement, not assumed Lighthouse scores. Large archived art experiments omitted locally via sparse checkout to fit disk; production assets unchanged.
