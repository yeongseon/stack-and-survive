This inventory is a review artifact, not a substitute for the runtime manifest or distribution approval. Browser raster bytes may vary with the export toolchain; re-review before import. The export inventory retains that geometry; `core-facilities.test.mjs` verifies the offset arithmetic, not runtime adoption or rendered pixel equivalence. Integration still must use and validate these offsets rather than guessing positions or retaining old sprite bounds. The verifier checks the exact inventory names, geometry and source hashes against the current generator as well as exported PNG/SVG hashes, so stale or altered exports cannot silently stand in for current art.
