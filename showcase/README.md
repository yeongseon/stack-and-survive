# Showcase — 발표·시연 자료

**[발표 슬라이드 열기](slides.html)** · [한국어 발표 대본](SPEAKER_NOTES.md) · [실제 게임](https://yeongseon.github.io/stack-and-survive/)

GitHub에서는 `slides.html`이 소스로 보입니다. 저장소를 내려받아 브라우저로 파일을 직접 열거나, **저장소 루트**에서 다음 명령으로 제공하세요. 외부 CDN·폰트·슬라이드 라이브러리는 필요하지 않습니다.

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8080/showcase/slides.html`을 엽니다. 이미지가 `../docs/images/`를 참조하므로 `showcase/`만 따로 옮기지 마세요. 발표 서버는 저장소 파일을 제공하므로 **loopback에서만 사용**하고 종료 시 Ctrl+C를 누르세요. Python 3는 이 선택적 문서 서버용이며 게임 실행 의존성이 아닙니다.

## 조작

| 키 / 버튼 | 기능 |
|---|---|
| ← / →, PageUp / PageDown | 이전 / 다음 슬라이드 |
| Home / End | 처음 / 마지막 슬라이드 |
| 아래 이전·다음 버튼 | 마우스·터치로 이동 |
| 인쇄 / PDF | 전체 슬라이드를 가로 페이지로 인쇄 |

슬라이드 번호는 URL의 `#slide-3` 형태로 저장됩니다. JavaScript가 없으면 모든 슬라이드가 문서 순서대로 표시됩니다. 자동 넘김·음악·시작 즉시 전체화면은 없습니다.

## 3분 발표 구성

총 8장, 슬라이드 설명 약 180초입니다. **별도의 실제 게임 한 판은 180초 + 인트로/결과 시간**이므로 3분 발표 안에 동시에 넣을 수 없습니다.

- 3분 제한: 슬라이드와 실제 스크린샷으로 설명합니다.
- 5분 이상: 설명을 줄이고 플레이를 추가하거나, 준비된 2분 **편집 영상**을 별도 구간으로 보여줍니다.
- 영상/스크린샷은 녹화·편집 자료임을 말합니다. 지금 진행되는 라이브 플레이처럼 설명하지 않습니다.

슬라이드의 모든 게임 이미지는 `24ca388` 실제 캡처입니다. [이미지 출처](../docs/images/README.md)를 유지하세요. `DEMO`는 자동화된 로컬 점수 이름이며, 실제 참가자나 공개 서버 검증을 뜻하지 않습니다.

## 발표 직전 확인

- [ ] 파일 또는 localhost에서 슬라이드·모든 이미지 로드 확인.
- [ ] 실제 발표 해상도에서 제목·캡션·아래 조작부가 잘리지 않는지 확인.
- [ ] PDF가 필요하면 인쇄 미리보기에서 **8페이지**와 가로 방향 확인. 머리글/바닥글은 끄고 필요한 경우 배경 그래픽을 켭니다.
- [ ] [공개 게임](https://yeongseon.github.io/stack-and-survive/)과 API 상태를 당일 확인. 실패 시 [대체 시연 계획](../docs/submission/DEMO_FALLBACK.md) 사용.
- [ ] 화면의 로컬/전역 리더보드를 구분하고 공용 보드에 테스트 점수를 반복 제출하지 않기.
- [ ] 실제 참가자·청취·권리 승인이 남아 있다는 사실을 숨기지 않기.

## 수정 및 공유

`slides.html`은 내용, `slides.css`는 화면/인쇄 스타일, `slides.js`는 탐색만 담당합니다. 대본을 바꾸면 슬라이드 순서·주장도 함께 맞추세요. 게임·백엔드 코드는 이 폴더에서 변경하지 않습니다.
