06 / ENGINEERING

화면과 규칙을 분리한
재현 가능한 엔진

같은 시작 상태·워크로드·행동 시점이면 같은 결과.

서버는 클라이언트 점수를 믿지 않고
지원 챌린지의 행동 기록을 다시 실행합니다.

닉네임은 인증 계정이 아니며, 리플레이 검증이 완전한 안티치트는 아닙니다.

BROWSER · GITHUB PAGESReact UI · Phaser world로컬 기록 · 결과 · 선택적 이름

↓ 행동 기록 + 챌린지 ID + 실행 ID + 이름

OPTIONAL SERVER · AZURE APP SERVICE검증 → 재실행 → 순위Node.js API · 저장된 검증 결과
공유 TypeScript 패키지schema · cloud-domain · scenarios · simulation

게임 플레이는 실제 Azure 리소스를 생성하지 않습니다.
